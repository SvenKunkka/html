This repository hosts the [HTML Standard](https://html.spec.whatwg.org/).

### Code of conduct

We are committed to providing a friendly, safe and welcoming environment for all. Please read and respect the [WHATWG Code of Conduct](https://wiki.whatwg.org/wiki/Code_of_Conduct).

### Contribution opportunities

We appreciate all contributions, see the [guidelines for contributing](CONTRIBUTING.md) for details, including information on how to build HTML output from the `source` file so you can preview your changes locally.

### Tests

Tests are in the `html/` directory of the [web-platform-tests repository](https://github.com/w3c/web-platform-tests).

## 中文项目说明

[WHATWG HTML Standard](https://html.spec.whatwg.org/) 源码仓库 [whatwg/html](https://github.com/whatwg/html) 的 Fork，用于阅读、讨论和参与 HTML 标准文档的维护。

**使用入口：** 直接访问 HTML Standard 阅读规范；本地从 `source` 生成预览及贡献步骤见 [CONTRIBUTING.md](CONTRIBUTING.md)，相关测试位于上游 web-platform-tests 的 `html/` 目录。

**范围说明：** 这是标准文档源码，不是普通网站应用；标准维护归属于 WHATWG 及其贡献者。

## English project overview

A fork of [whatwg/html](https://github.com/whatwg/html), the source repository for the [WHATWG HTML Standard](https://html.spec.whatwg.org/), supporting reading, discussion, and contributions to the specification.

**Getting started:** Read the HTML Standard online; see [CONTRIBUTING.md](CONTRIBUTING.md) for generating previews from `source` and contributing. Related tests live in the upstream web-platform-tests `html/` directory.

**Scope:** This is specification source rather than a conventional web application. The standard is maintained by WHATWG and its contributors.
